# Catalog Mismatch Checker

A Python tool that compares retailer (1P) catalog data with third-party (3P) seller data and flags mismatches in **title, brand, color and price**, then produces an Excel report with summary tables.

## Problem
In e-commerce marketplaces, the same item often has different data across sources. Mismatches hurt search, customer trust, and catalog integrity, and checking them by hand across thousands of SKUs is slow and error-prone.

## Data
Synthetic data generated by `generate_data.py` (2,000 1P items, ~1,985 3P items) with deliberately planted errors: title, brand, color and price differences, plus items missing on either side. Swap in your own CSVs with the same columns to use it on real data.

## Approach
1. Load the 1P and 3P files with pandas
2. Outer-merge on `item_id` to find matched, missing and extra items
3. Normalize text (case, extra spaces) so only real differences are flagged
4. Compare each field (price uses a small tolerance)
5. Summarize mismatches by type and by category
6. Export everything to `mismatch_report.xlsx`

## Results (sample run)
| Metric | Value |
|---|---|
| Matched items | 1,975 |
| Items with 1+ mismatch | 403 |
| Catalog accuracy | 79.6% |
| Missing in 3P / Not in 1P | 25 / 10 |

Price (7.0%) and title (6.1%) were the most common mismatch types. Apparel had the highest category mismatch rate (23.1%).

## Business Insights
*(Based on synthetic sample data, for demonstration.)*

- **Overall:** 20.4% of matched items had at least one mismatch, so catalog accuracy was 79.6%.
- **Price is the biggest issue:** 138 items (7.0%) had price differences, averaging 13.5%. 85 of them were off by more than 10%, which could affect price consistency and customer trust.
- **Category focus:** Apparel (23.1%) and Electronics (22.5%) had the highest mismatch rates; Home & Kitchen was lowest (17.8%).
- **Multi-field errors:** 31 items had two or more mismatched fields, which suggests poor source data and should be prioritized first.
- **Coverage gaps:** 25 items were missing in 3P and 10 appeared in 3P without a 1P record.

**Recommendations**
1. Fix high-value price mismatches (over 10% difference) first.
2. Start Apparel and Electronics category reviews with the sellers involved.
3. Add automatic checks at seller onboarding to catch title and brand issues earlier.
4. Track weekly accuracy % as the main KPI (target 95%+).

See the full requirements in [`BRD_catalog_quality_monitoring.md`](BRD_catalog_quality_monitoring.md).

## How to run
```bash
pip install -r requirements.txt
python generate_data.py     # creates retailer_1p.csv and seller_3p.csv
python make_report.py       # creates mismatch_report.xlsx
```
